# Тайный Санта

## Посмотреть локально

Открой `Открыть сайт.cmd` или `index.html` в Chrome или Edge. Нажми на коробку или **«Открыть подарок»**. При открытии играет `assets/jingle-bell-rock.mp3`. Музыку можно выключить кнопкой под коробкой.

## Провести жеребьёвку

Нужен Node.js. Скопируй `participants.example.txt` в `participants.local.txt` и впиши имена в UTF-8, по одному на строку. Если имена совпадают, добавь подписи, по которым участники отличат друг друга.

Для локальной проверки запусти в папке проекта:

```powershell
node draw.mjs
```

Для рассылки сначала опубликуй сайт и передай генератору HTTPS-адрес главной страницы. Подставь свой адрес:

```powershell
node draw.mjs "https://USERNAME.github.io/Secret_Santa/"
```

Генератор запишет в `invitations.local.txt` имена участников и персональные ссылки. При открытии ссылки участник увидит своё имя, а после открытия коробки — имя того, кому дарит. Рассылай ссылки по одной. Действующая ссылка всегда раскрывает тот же результат, даже на другом устройстве. Сохрани файл с готовыми приглашениями. Если он уже существует, генератор завершится без перезаписи.

## Проверить результаты

Генератор проверяет каждую ссылку перед сохранением. После жеребьёвки можно ещё раз сверить готовые приглашения с текущим списком участников. Команда ниже показывает только итог проверки:

```powershell
node draw.mjs --verify
```

Если хочешь увидеть, кто кому дарит, добавь `--show-pairs`:

```powershell
node draw.mjs --verify --show-pairs
```

Обе команды читают существующие файлы. Распределение и ссылки при этом сохраняются.

## GitHub Pages

Для публикации нужны `index.html`, `styles.css`, `santa.js`, `assets/holiday-window.webp` и `assets/favicon.png`. Включи публикацию из корня выбранной ветки. Локальный список участников и готовые ссылки исключены из Git через `.gitignore`. Для музыки при публикации нужен файл `assets/jingle-bell-rock.mp3` в той же ветке, что и сайт.
