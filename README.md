# Тайный Санта

## Посмотреть локально

Открой `Открыть сайт.cmd` или `index.html` в Chrome или Edge. Нажми **«Узнать, кому я дарю»**. При раскрытии конверта включается музыка, если в папке `assets` есть `jingle-bell-rock.mp3`. Её можно выключить кнопкой под конвертом.

## Провести жеребьёвку

Нужен Node.js. Скопируй `participants.example.txt` в `participants.local.txt` и впиши имена в UTF-8, по одному на строку. Если имена совпадают, добавь подписи, по которым участники отличат друг друга.

Для локальной проверки запусти в папке проекта:

```powershell
node draw.mjs
```

Для рассылки сначала опубликуй сайт и передай генератору HTTPS-адрес главной страницы. Подставь свой адрес:

```powershell
node draw.mjs "https://USERNAME.github.io/Secret_Santa/"
```

Генератор запишет в `invitations.local.txt` имена участников и персональные ссылки. При открытии ссылки участник увидит своё имя, а после раскрытия конверта — имя того, кому дарит. Рассылай ссылки по одной. Действующая ссылка всегда раскрывает тот же результат, даже на другом устройстве. Сохрани файл с готовыми приглашениями. Если он уже существует, генератор завершится без перезаписи.

## GitHub Pages

Для публикации нужны `index.html`, `styles.css`, `santa.js` и `assets/winter.webp` и `assets/favicon.png`. Включи публикацию из корня выбранной ветки. Локальный список участников, готовые ссылки и скачанный MP3 исключены из Git через `.gitignore`. Опубликованный сайт работает и без MP3.
